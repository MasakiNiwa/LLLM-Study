# 落ち着いたダークテーマの作り方

ダークモードは「暗い部屋や夜に、目を疲れさせずに落ち着いて使う」ためのものです。
ただ背景を黒くして、ライトモードの鮮やかな色をそのまま載せると、
**濃紺の背景・発光するようなアクセント・彩度の高い赤や緑**が目に刺さり、かえって疲れます。

LLLM Study では、Claude や ChatGPT のダークモードを参考に、次の考え方で作り直しました。
新しいリポジトリでも、この文書と `src/index.css` の末尾の配色をそのまま使えます。

## 1. 考え方

| 方針                                               | 理由                                                                                                                                       |
| -------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| **背景は青みのないグレー**（真っ黒・濃紺にしない） | 濃紺（Tailwind の slate-950 など）は青い光が強く、冷たく落ち着かない。真っ黒（#000）は文字とのコントラストが強すぎて、文字がにじんで見える |
| **面の明るさの差は小さく、でも見分けられる程度に** | 背景・カード・ボタン・枠を、明るさの段差（約 0.05 ずつ）で区別する。影や強い枠線に頼らない                                                 |
| **文字は真っ白にしない**（#ececec 前後）           | 純白は背景との差が大きすぎてまぶしい。本文は少し落とし、補足はさらに落とす                                                                 |
| **アクセントは 1 色だけ、彩度を抑える**            | ボタンの色は「押せる」と分かれば十分。鮮やかな紫や青はやめ、くすんだ色にする                                                               |
| **状態の色（正解・不正解・注意）は彩度を半分に**   | 緑・赤・黄は意味を伝えるために残すが、明るさはそのままで彩度だけを下げる                                                                   |
| **ライトモードは変えない**                         | 明るい場所では鮮やかな色の方が読みやすいので、ダークモードだけを差し替える                                                                 |

## 2. 配色（このアプリの 3 つ）

設定の「表示」→「ダークモードの配色」で選べます（既定は「落ち着いたグレー」）。

| 配色                          | 背景 / カード                                   | アクセント         | 参考                             |
| ----------------------------- | ----------------------------------------------- | ------------------ | -------------------------------- |
| 落ち着いたグレー（`neutral`） | 色味のないグレー（oklch の彩度 0）              | くすんだ青灰色     | ChatGPT のダークモード           |
| あたたかいグレー（`warm`）    | ほんの少し黄みのあるグレー（彩度 0.004〜0.006） | くすんだテラコッタ | Claude のダークモード            |
| 鮮やか（`vivid`）             | 濃紺（Tailwind の slate そのまま）              | 鮮やかな紫         | 以前の配色。好みの人のために残す |

グレーの明るさ（oklch の L）は、落ち着いた 2 つで共通です。

| 段  | 使いどころ                 | L     |
| --- | -------------------------- | ----- |
| 950 | ページの背景               | 0.225 |
| 900 | カード・下部ナビ           | 0.275 |
| 800 | 押したとき・チップ・薄い枠 | 0.330 |
| 700 | 枠線・選んでいるタブ       | 0.395 |
| 600 | 無効な部品                 | 0.470 |
| 500 | 補足の文字                 | 0.635 |
| 400 | 2 番目の文字               | 0.730 |
| 100 | 本文                       | 0.935 |

## 3. 作り方（Tailwind CSS 4）

Tailwind 4 の色は **すべて CSS 変数**（`--color-slate-900` など）として参照されます。
そこで、ダークモードのときだけ変数を差し替えれば、**部品のクラス（`dark:bg-slate-900` など）を 1 つも変えずに**配色をまとめて切り替えられます。

```css
/* src/index.css の末尾（抜粋） */
.dark[data-dark-palette='neutral'] {
  --color-slate-950: oklch(0.225 0 0);
  --color-slate-900: oklch(0.275 0 0);
  /* …50〜950 まで */
  --color-accent-600: oklch(0.5 0.055 255);
  /* …アクセントも */
}
.dark[data-dark-palette='neutral'],
.dark[data-dark-palette='warm'] {
  /* 状態の色は、明るさと色相はそのままで、彩度だけ半分にする */
  --color-emerald-400: oklch(0.765 0.089 163.2);
  --color-rose-600: oklch(0.586 0.127 17.6);
  /* … */
}
```

- 切り替えは `<html class="dark" data-dark-palette="neutral">`。初回の描画の前に `index.html` のスクリプトで付ける（ちらつきを防ぐ）
- 部品を作るときは、これまでどおり `bg-white dark:bg-slate-900` のように書く。**部品の中で色の値を直接書かない**（差し替えが効かなくなる）
- 状態の色の値は、Tailwind の既定の値（`node_modules/tailwindcss/theme.css`）の彩度を 0.5 倍して作る
- 背景を暗くする幕（`dialog::backdrop`）や、グラフの色など、変数を使っていない色も忘れずに合わせる
- ブラウザのアドレスバーの色（`<meta name="theme-color">`）も、表示している背景の色に合わせる（`src/app/useTheme.ts`）

## 4. 切り替えやすくする

- ヘッダー（ホーム・設定）と PC のサイドバーに、ライト・ダークの切り替えボタン（太陽・月）を置く。押すと今と反対のテーマに固定する（`src/app/ThemeToggle.tsx`）
- 設定では「端末に合わせる / ライト / ダーク」と、ダークモードの配色を選べる。配色は小さな見本（背景・カード・文字・アクセント）を並べて選ばせる

## 5. 確かめること

- 実機（スマホ）で、暗い部屋で 10 分ほど使って疲れないか
- 選んでいるタブ・下部ナビの現在地・入力欄の枠など、**小さな明るさの差で表しているもの**が見分けられるか
- 正解・不正解・注意の色が、彩度を下げても区別できるか（色だけでなく、アイコンや文字でも伝える）
- 補足の文字（500）が背景に対して読めるか（コントラスト比 4.5 以上が目安）
