# 画面づくりのガイド（スマホ / PC）

LLLM Study の画面の作り方と、ほかのアプリでも使える部品のまとめです。
新しいリポジトリでは、ここに挙げたファイルをコピーして使ってください（React 19 + Tailwind CSS 4）。

## 1. レイアウト

|                | スマホ（〜767px）                                | PC（768px〜）               |
| -------------- | ------------------------------------------------ | --------------------------- |
| ナビゲーション | 画面下部のナビ（`AppLayout.tsx` の `BottomNav`） | 左のサイドバー（`SideNav`） |
| ヘッダー       | ロゴ・ページ名・ページごとの操作・右端にヘルプ   | ページ名・ページごとの操作  |
| シート         | 画面の下から出るボトムシート                     | 画面中央のダイアログ        |

- ナビの項目は `src/app/navItems.ts` にまとめる。ページを増やすときはここと `App.tsx` のルートに足す
- 下部ナビは 7 つまで。幅の狭い端末（〜399px）ではラベルの文字を少し小さく詰める
- チャット以外の AI の機能は「AI練習」のシートにまとめる（`AI_TOOL_ITEMS` に足すと、スマホのシートと PC のサイドバーの両方に出る）
- 高さは `h-dvh`。スクロールするのは各ページの本体（`PageBody`）だけにし、ヘッダーと下部ナビは固定する
- ノッチ・ジェスチャーバーの分は `pt-safe` / `pb-safe`（`env(safe-area-inset-*)`）で空ける
- アプリのヘッダーには GitHub へのリンクを置かない（ソースコードへのリンクはヘルプにだけ置く）

## 2. 部品（`src/components/ui/`）

| 部品                                    | 使いどころ                                                                                         |
| --------------------------------------- | -------------------------------------------------------------------------------------------------- |
| `BottomSheet`                           | 画面に収まりきらない情報・選択肢・補足を、ページを溢れさせずに見せる（下で詳しく）                 |
| `Dialog`                                | 入力フォームや確認など、中央に出すもの                                                             |
| `ConfirmDialog`                         | 消す・やり直すなど、取り消せない操作の確認                                                         |
| `Card` / `Section`                      | 見出し付きのカード。`collapsible` で見出しを押して折りたためる（開閉は `storageKey` ごとに覚える） |
| `Field`                                 | 設定の 1 行（ラベル・説明・入力）                                                                  |
| `Chip`                                  | 選択式の小さなボタン（オン・オフ）                                                                 |
| `Select` / `Switch` / `Slider` / `Tabs` | 入力                                                                                               |

## 3. ボトムシート（`BottomSheet.tsx` + `useSheetSwipe.ts`）

```tsx
const [open, setOpen] = useState(false);

<BottomSheet open={open} onClose={() => setOpen(false)} title="学習する教材" expandable>
  <Options />
</BottomSheet>;

// シートの中から、アニメーションして閉じる
function Options() {
  const close = useSheetClose();
  return (
    <button
      onClick={() => {
        choose();
        close();
      }}
    >
      …
    </button>
  );
}
```

- **下へ払うと閉じる**: 引き下げた距離（シートの高さの 20%、最大 120px）か、最後のひと払いの速さ（0.35px/ms 以上）で閉じる。足りなければ元に戻る
- **上へ払うと広がる**（`expandable`）: 中身が収まりきっていないときだけ、画面の高さいっぱいまで広げる。広げた状態で下へ払うと元の高さに戻る
- つまみを押す・背景を押す・Esc・×ボタンでも閉じる（どれも下へ滑らせるアニメーションのあとで閉じる）
- 指の操作は **touch イベント**で受ける。pointer イベントだとブラウザのスクロールが先に始まったときに `pointercancel` で打ち切られ、「たまに閉じない」ことになるため
- 最初のひと動き（6px）で「払う」か「スクロール」かを決め、決めたら最後までそのまま扱う。中身をスクロールしている途中（`scrollTop > 0`）は払う操作を始めない
- 払ったあとに続く click は 1 回だけ止める（ボタンの上から払っても、ボタンを押したことにしない）
- ネイティブの `<dialog>`（`showModal`）なので、フォーカスはシートの中に閉じ込められる。PC では払う操作は使わず、中央のダイアログとして出す
- `prefers-reduced-motion` ではアニメーションしない

> 払う操作の作り方は、忘却曲線カレンダー（[MasakiNiwa/Forgetting-Curve-Calendar](https://github.com/MasakiNiwa/Forgetting-Curve-Calendar) の `assets/js/ui/overlays.js`）の実装を React 向けに移したものです。

### 使いどころの例（このアプリ）

- 「AI練習」の選択（例文クイズ・会話練習・AI モデルへの入口）
- 学習する教材の選択
- 学習画面の表示（文字の大きさ・余白）と、時間を測る設定（スライダーと数字の欄。`DurationField`）
- 学習中のカードの詳細（学習状況・評価の履歴）。**答えを見る前は、答えが分かる内容を出さない**
- 長文読解の本文を大きく表示
- 自分の答えを書く欄（入力欄に `data-autofocus` を付けると、開いたときにそこへフォーカスする）

## 4. 画面に収める工夫

- 学習画面はカードの文字の大きさを選べる（CSS の `zoom`）。画面の高さが低い端末（760px 以下）では自動で余白を詰める（`useStudyLayout.ts`）
- 長い本文は枠の中でスクロールし、大きく読みたいときはボトムシートで開く
- 設定・ヘルプは見出しで折りたためるようにして、ページを短く保つ

## 5. 色とテーマ

- アクセント色は `src/index.css` の `--color-accent-*`（oklch）。ダークモードは `dark:` で必ず両方を指定する
- テーマは「端末に合わせる / ライト / ダーク」。初回描画前に `index.html` のスクリプトで適用してちらつきを防ぐ
- グラフの色は `--viz-*` にまとめる（ライト・ダークの両方で読めることを確かめる）

## 6. 文章

- 画面の言葉はやさしい日本語で、専門用語は言い換えるか説明を添える（例: 「FSRS」→「記憶のアルゴリズム（FSRS）」）
- 取り消せない操作は、何が消えて何が残るかを確認画面に書く
