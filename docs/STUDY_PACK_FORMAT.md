# 教材パック形式（lllm-study-pack v1）

学習アプリ「LLLM Study」に取り込む学習教材の形式です。
外部の AI（ChatGPT / Claude / Gemini など）にこのファイルを渡して、教材の JSON を作ってもらうことを想定しています。

> このファイルは `src/lib/packs/spec.ts` から自動生成されます（`npm run packs`）。手で編集しないでください。

## ルール

- 出力は JSON だけにする（前置きや説明文は付けない）。全体を 1 つの ```json コードブロックに入れてもよい
- "format" は "lllm-study-pack"、"version" は 1 にする
- "id" はパックを表す英数字の ID（例: "en-basic-verbs-001"）。同じ教材を作り直すときは同じ ID と各項目の ID を使い、"revision" を増やす（学習記録が引き継がれる）
- 各項目の "id" はパック内で一意にする（例: "v-take", "p-no-worries"）
- 各項目の "type" で種類を指定する。種類ごとに必須のキーが違う
- "subject" には分野を表す短い英語（例: english, bookkeeping, history, programming）を入れる
- 説明・意味・訳・解説は「説明の言語」で書く。語学の教材では、見出し語・例文を「学ぶ言語」で書く
- テーマに合った種類を選ぶ（語学なら単語・フレーズ、知識や資格なら一問一答・穴埋め・選択問題など）。種類は組み合わせてもよい
- 1 つの項目では 1 つのことだけを問い、答えが一つに決まるようにする。解説には覚えるための要点を短く書く
- 事実と異なる内容を入れない。自信がない情報は省略する
- 長文読解・会話文の聞き取りなど、複数の問題が同じ本文を使うときは、本文をパックの "passages"（{ "id", "title", "text", "translation" }）に入れ、各問題の "passage" にその id を書く。本文は問題の上に表示される

## パック全体のキー

| キー | 必須 | 説明 |
| --- | --- | --- |
| format | ✓ | 固定値 `"lllm-study-pack"` |
| version | ✓ | 固定値 `1` |
| id | ✓ | パックの ID（英数字と `.` `_` `-`。同じ ID で取り込むと更新） |
| title | ✓ | タイトル |
| items | ✓ | 項目の配列（1〜5000 個） |
| description |  | 説明 |
| subject |  | 分野（例: english） |
| language |  | `{ "target": 学ぶ言語, "explanation": 説明の言語 }`（BCP 47） |
| level |  | 難易度の目安（例: CEFR A2） |
| tags / author / license / source |  | タグ・作者・ライセンス・作り方や出典 |
| revision |  | パックの版（更新するたびに増やす） |

## 項目の種類

| type | 名前 | 内容 |
| --- | --- | --- |
| vocab | 単語 | 単語。term（見出し語）と meanings（意味の配列）が必須。reading（IPA）・pos（品詞）・examples（例文と訳）・collocations・synonyms・antonyms・forms（不規則な活用形。例: took, taken）・notes は任意 |
| phrase | フレーズ | フレーズ・表現。phrase と meaning が必須。situation（使う場面）・examples・notes は任意 |
| qa | 一問一答 | 一問一答（どの分野にも使える）。question と answer が必須。accepted（別解・略称・表記揺れなど、正解にしてよい答え）・explanation・hints は任意 |
| cloze | 穴埋め | 穴埋め。text の中で答えにする部分を {{ }} で囲む（例: "I look {{forward}} to it."）。translation・hint・explanation は任意 |
| choice | 選択問題 | 選択問題。question・choices（2〜6 個）・answer（正解の番号。0 始まり）が必須。explanation は任意 |
| order | 並べ替え | 並べ替え。answer（正しい文）が必須。chunks（並べ替える語句を正しい順に。日本語など空白で区切らない言語では必須）・prompt（訳や問題文）・explanation は任意 |
| journal | 仕訳 | 仕訳（簿記・会計）。question（取引の内容）・debit（借方の行）・credit（貸方の行）が必須。各行は { "account": 勘定科目, "amount": 金額（数値） }。借方と貸方の合計を一致させる。accounts（選択肢に足す紛らわしい科目）・unit（単位。既定は円）・explanation は任意 |
| multi | 複数選択 | 複数選択（正しいものをすべて選ぶ）。question・choices（3〜8 個）・answers（正解の番号の配列。0 始まり、1 つ以上。全部を正解にはしない）が必須。explanation は任意 |
| numeric | 数値入力 | 数値入力（計算問題）。question・answer（正解の数値。単位は付けない）が必須。unit（単位。例: 円, %）・tolerance（許容する誤差）・hints・explanation は任意 |
| truefalse | ○× | ○×（正誤）。statement（判断する文）・answer（正しければ true、誤りなら false）が必須。explanation（誤りの文ではどこが誤りか）は任意 |
| match | 組み合わせ | 組み合わせ。pairs（[{ "left": 語句, "right": 対応する語句 }] を 2〜8 組。右の語句はどれも違うものにする）が必須。prompt（指示）・explanation は任意 |
| table | 表の穴埋め | 表の穴埋め（返済表・計算表など）。question・columns（列の見出し）・rows（行の配列。各マスは文字列で、答えにするマスを {{ }} で囲む）が必須。explanation は任意 |

どの種類にも `id`（必須）・`tags`・`notes` を付けられます。
